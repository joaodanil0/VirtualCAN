CAN FD · Temporização e BRS

Taxa nominal e taxa de dados

CAN FD pode usar uma taxa de bits para a arbitragem e outra, opcionalmente mais alta, para a parte de dados. O bit BRS controla a troca; os valores numéricos das taxas são configurados nos nós, não codificados dentro do frame.

Bitrate nominal · dbitrate · BRS

O que cada taxa significa

Taxa nominal

É a taxa base da rede CAN. CAN clássico usa essa taxa durante o frame inteiro. Em CAN FD, ela continua sendo usada na arbitragem e em outras partes do frame fora da fase de dados acelerada.

Taxa de dados

É a taxa configurada para a fase de dados do CAN FD quando a troca de bitrate está habilitada. Normalmente é maior que a nominal, mas o valor depende do hardware e do projeto da rede.

Unidade: ambas as taxas são medidas em bits por segundo. Por exemplo, 500000 representa 500 kbit/s e 2000000 representa 2 Mbit/s.

Como o BRS controla a troca

BRS (Bit Rate Switch) é um bit do frame CAN FD. Seu valor informa se o frame solicita uma troca para a taxa de dados:

Valor de BRSComportamentoO frame continua sendo CAN FD?
Dominante (0)Não há troca. A arbitragem e os dados usam a taxa nominal.Sim. O frame ainda pode transportar até 64 bytes.
Recessivo (1)O frame solicita a taxa de dados após o ponto de amostragem do bit BRS.Sim. A fase mais rápida só ocorre se os nós estiverem configurados de forma compatível.
BRS não contém o valor da taxa. Ele apenas seleciona se a troca ocorre. A taxa nominal e a taxa de dados são configuradas separadamente em cada interface.

Em quais partes do frame cada taxa é usada?

Com BRS habilitado, a mudança acontece dentro do próprio frame:

Taxa nominalSOF · ID · arbitragem · FDF · res
Taxa nominalbit BRS
Taxa de dadosESI · DLC · payload · sequência CRC
Retorno à nominaldelimitador CRC
Taxa nominalACK · EOF

A troca para a taxa de dados ocorre no ponto de amostragem do BRS recessivo. O retorno à nominal ocorre no ponto de amostragem do delimitador CRC. O diagrama é conceitual, não está em escala.

1

SOF e arbitragem: todos os nós usam a taxa nominal para sincronizar e disputar o barramento.

2

Bit BRS: é transmitido na taxa nominal. Se for recessivo, os nós compatíveis mudam de taxa no ponto de amostragem desse bit.

3

Fase de dados: ESI, DLC, payload e sequência CRC usam a taxa de dados enquanto a troca está ativa.

4

CRC delimiter: no ponto de amostragem desse delimitador, os nós retornam à taxa nominal para ACK e EOF.

Com BRS e sem BRS

BRS = 0

O frame é CAN FD, mas não troca para a taxa de dados. A arbitragem, o payload maior e os campos finais são enviados todos na taxa nominal.

BRS = 1

O frame solicita a taxa de dados para a fase acelerada. A arbitragem continua na taxa nominal, o que mantém o mecanismo de disputa em uma taxa única e conhecida pelos nós.

BRS controla a taxa, não o formato nem o comprimento. FDF identifica CAN FD; DLC codifica o comprimento do payload.

Exemplo de configuração

Em uma interface CAN FD física chamada can0, esta configuração usa 500 kbit/s nominais e 2 Mbit/s na fase de dados:

sudo ip link set can0 type can bitrate 500000 dbitrate 2000000 fd on
sudo ip link set can0 up

Uma transmissão com BRS habilitado solicita 2 Mbit/s na fase de dados; um frame FD com BRS desabilitado permanece a 500 kbit/s, embora possa transportar mais de 8 bytes.

Compatibilidade física: todos os nós CAN FD ativos precisam suportar a configuração nominal e a taxa de dados. A qualidade do transceptor, do cabeamento, da topologia e da temporização limita a taxa utilizável.

Cuidados ao validar

Taxas devem coincidir

Se transmissor e receptores configurarem valores incompatíveis, os bits da fase de dados podem ser amostrados incorretamente, causando erros de frame e retransmissões.

vcan não mede bitrate

Uma interface vcan valida o fluxo de software SocketCAN, mas não possui clock de barramento, transceptor nem temporização elétrica real. Ela não comprova que BRS funciona no hardware.

Para detalhes dos campos FDF, BRS e ESI, consulte Estrutura do frame CAN FD. Para comparar CAN clássico e CAN FD, consulte CAN clássico vs CAN FD.

A taxa nominal e a taxa de dados configuram temporizações físicas distintas no CAN FD. Consulte o manual do controlador e a especificação da rede antes de habilitar BRS em hardware.
